🍅 专注/番茄钟 API 使用说明
======================================================================

【获取番茄钟记录】
  GET https://api.ticktick.com/api/v2/pomodoros
  
【获取专注记录】
  GET https://api.ticktick.com/api/v2/focusRecords
  
【获取统计】
  GET https://api.ticktick.com/api/v2/statistics/pomo
  GET https://api.ticktick.com/api/v2/statistics/focus
  
【可能的开始/停止专注】
  POST https://api.ticktick.com/api/v2/focus
  Body: { taskId: "xxx", duration: 1500000 }  // 25分钟
  
【批量同步所有数据】
  GET https://api.ticktick.com/api/v2/batch/check/0
  返回: 项目、任务、标签、习惯等所有数据

⚠️ 认证方式:
  1. Cookie: t=<session_token>
  2. 需要通过 POST /user/signin 登录获取 token
  
你现在的 Open API token (tp_xxx) 是 v1 API 的，
v2 API 需要用户登录后的 session token。
